# Rockets

The airframes. Icarus-I is the one on the bench. Each later rocket takes the next number, and keeps that number for every flight it makes.

## Icarus-I

A LOC Precision LOC IV, built for a Level 1 certification flight.

[icarus-i/](icarus-i/) is the bench record: what the parts are, how they went together, and the photographs. Flights will be dated notes in `icarus-i/flights/`, starting with the first launch of this rocket.

The coupler is held with rivets, so it can come out and an avionics bay can take its place after certification. The Level 1 flight flies without a flight computer.
