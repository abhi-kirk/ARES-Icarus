# Icarus-I

The first airframe. A LOC Precision LOC IV, built for an L1 certification attempt.

This folder is the bench record: what the parts actually are, and what happened in each work session. Flights go in `flights/`, one note per launch, starting with the first flight of this rocket. A later rocket is Icarus-II, not the next launch of this one.

The packing slip, the manufacturer instruction PDF, and the build-video transcripts stay off the repo.
